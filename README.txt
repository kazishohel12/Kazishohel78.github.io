HOW TO PUBLISH (hosting mobilephoneunlocker.com)
------------------------------------------------
1. Buy the domain mobilephoneunlocker.com (Namecheap, GoDaddy, etc.)
2. Host the files on any static host:
   - cPanel hosting: upload everything into the public_html folder
   - Or free options: Cloudflare Pages / Netlify / GitHub Pages
3. Point the domain's DNS to your host (they give you the nameservers).
4. Open https://mobilephoneunlocker.com — done.

NOTE: The login/register forms and payment buttons are demo (front-end
only). For a real ordering system with accounts and automated delivery,
connect a backend panel such as Dhru Fusion (like unlockerbd.com uses)
later.
